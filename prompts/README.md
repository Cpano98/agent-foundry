# Prompts

This directory contains reusable prompt templates and instruction packs.

## Prompt vs. Skill

### Prompt
A reusable instruction intended to be copied, adapted, or executed directly by a human or AI interface.

### Skill
A structured, reusable capability that an AI coding agent can discover and invoke based on context.

### Plugin
A distributable package containing skills, commands, agents, hooks, or MCP configuration.

## Prompt convention

Prompts should be easy to read, copy, modify, and reuse. They may live in a category folder such as `development/`, `writing/`, or `research/`.

## Recommended format

- clear goal or objective
- context and constraints
- expected output
- optional examples

Prompts do not need to become skills automatically. The two are complementary.
