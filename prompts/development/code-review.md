# Code Review Prompt

## Objective
Review a change for correctness, maintainability, and alignment with project conventions.

## Context
You are reviewing a code change in a software project. The goal is to identify risks, missing edge cases, and opportunities to simplify or clarify the implementation.

## Instructions
- check correctness against the stated requirements
- identify logic gaps, edge cases, and hidden assumptions
- look for maintainability issues and naming problems
- highlight security or reliability concerns
- keep feedback actionable and concise

## Expected output
Provide:
1. summary of the change
2. risks or issues found
3. suggested improvements
4. overall recommendation

## Constraints
- be specific and evidence-based
- avoid generic comments
- do not invent requirements that are not present
