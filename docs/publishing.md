# Publishing and distribution

This repository is designed to support future publishing and community contribution.

## Distribution paths

- GitHub repository browsing
- Claude Code marketplace integration
- Cursor and other Agent Skills-compatible discovery
- direct downstream consumption by teams and contributors

## What to publish

Publish resources that are:

- useful
- clear
- portable
- documented
- tested or reasonably validated

## Quality bar

Avoid fake examples, placeholder material, or low-value directories. Every addition should either solve a real problem or demonstrate a clear packaging pattern.
