# Prompts

Prompts are reusable instructions that a human or AI interface can copy, adapt, and run directly.

## Prompt vs. skill

A prompt is usually a disposable instruction package. A skill is a reusable capability an AI agent can discover and use in context.

## Recommended structure

```text
prompts/
└── development/
    └── code-review.md
```

## Suggested content

- objective
- context
- constraints
- expected output
- optional examples

A prompt does not need to be converted into a skill simply because it is useful.
