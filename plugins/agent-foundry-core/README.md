# agent-foundry-core

This is the minimal plugin example for Agent Foundry.

It demonstrates the packaging pattern used by the broader repository:

- a Claude plugin manifest in `.claude-plugin/plugin.json`
- a reusable Agent Skills-compatible skill in `skills/`
- a small, portable structure that can grow into a richer plugin package

## Included resource

- `skills/example-skill` — an example Agent Skill for demonstration and reuse.
