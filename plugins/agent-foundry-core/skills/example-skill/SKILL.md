# Example Skill

Use this skill when you need a lightweight demonstration of the Agent Foundry packaging model.

## What it does

- explains the repo structure
- points contributors to the canonical skill model
- demonstrates a valid Agent Skills entry point

## When to use it

- when exploring the repository for the first time
- when verifying compatibility with Agent Skills-based clients
- when testing a new plugin packaging workflow

## Notes

This is intentionally minimal. Real skills in Agent Foundry should be more specific, tested, and documented, with clear steps, references, and examples.
