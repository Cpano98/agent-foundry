# Agents

This directory is reserved for agent definitions, workflow packs, or reusable agent blueprints.

Agent resources are distinct from skills. Skills describe reusable capabilities, while agents are often more task-oriented systems that compose those capabilities.

## Recommended conventions

- keep agent definitions small and portable
- document primary inputs and outputs
- define which skills, plugins, or commands they depend on
- keep names descriptive and lowercase, using kebab-case
